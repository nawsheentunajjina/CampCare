# CampCare
Rural Health Access Platform

## Project Overview

**CampCare** is a web-based platform designed to support rural healthcare workers in managing child records, vaccinations, health camps, attendance, and vaccination reminders.

## Key Features

* Child and family record management
* Vaccination tracking and due-list
* Camp scheduling and attendance
* Worker and supervisor management
* Search, filtering, and sorting
* Telegram and SMS reminders
* Dashboard and reports

## Technologies

**Frontend:** HTML, CSS, JavaScript
**Backend:** PHP
**Database:** MySQL
**Tools:** XAMPP, Git & GitHub
